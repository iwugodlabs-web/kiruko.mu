# Payroll — Simple Guide

How to pay your staff with Kiruko. No tech knowledge needed.

You set things up **once**, then each month you just **Run → Check → Finalize**.

```
      SET UP ONCE                        EVERY MONTH
  ┌───────────────────┐         ┌─────┐   ┌───────┐   ┌──────────┐
  │  staff + their pay │ ─────►  │ Run │──►│ Check │──►│ Finalize │ ──►  📄 Payslips
  └───────────────────┘         └─────┘   └───────┘   └──────────┘
```

---

## Set up once

```
   1                          2                         3
 ┌──────────────────┐     ┌──────────────────┐     ┌──────────────────┐
 │ Track attendance?│ ──► │   Add your staff │ ──► │  Check their pay │
 │   ON / OFF       │     │ (name, salary…)  │     │                  │
 └──────────────────┘     └──────────────────┘     └──────────────────┘
   Settings → Payroll       Team Members →            Payroll →
                            Add employee              Salary Configuration
```

**1. Choose how pay works** — *Settings → Payroll*
- **Track attendance?** Turn **ON** if staff clock in and out (missed days reduce pay). Turn **OFF** to always pay full salary.

**2. Add your staff** — *Team Members → Add employee*
- Fill in their name, department, and salary (or hourly rate). They're ready for payroll.

**3. Check their pay** — *Payroll → Salary Configuration*
- Each person has their own pay card you can open and edit anytime.

✅ Setup done.

---

## Every month (3 steps)

```
   1. GET READY            2. START & CHECK          3. FINALIZE
 ┌──────────────────┐    ┌──────────────────┐     ┌──────────────────┐
 │ approve clock-ins│    │ payslips appear  │     │  payslips become │
 │ approve overtime │──► │ for everyone —   │ ──► │  official 🔒     │
 │ add any leave    │    │ open to check    │     │  download/share  │
 └──────────────────┘    └──────────────────┘     └──────────────────┘
  (skip if you don't       Payroll →                 click "Finalize"
   track attendance)       Payroll Runs →
                           Start payroll
```

**1. Get the month ready**
- Tracking attendance? Approve clock-ins (*Clock-in Review*), approve overtime (*Overtime*), add leave (*Leave*).
- Not tracking? Skip straight to step 2.

**2. Start payroll & check it** — *Payroll → Payroll Runs → Start payroll*
- Pick the month. A payslip appears for everyone with the numbers worked out. Open a few to check.

**3. Finalize**
- Click **Finalize** to make the payslips official. Done — download and share them.

## What's on a payslip

```
  ┌──────────────────────────────────────────┐
  │  GROSS   = salary + allowances + overtime │  ← what they earned
  │            + bonus                        │
  │  − Taxes (CSG, NSF, PAYE)                  │  ← taken off automatically
  │  − Unpaid leave (if any)                  │
  │  ────────────────────────────────────────│
  │  NET PAY = what the employee receives 💰  │
  └──────────────────────────────────────────┘
```

---

## Fixing one person after you've finalized

Finalized payslips are **locked** — you don't re-run the whole payroll for one mistake. You make a **Correction** for just that person. The original payslip stays untouched; the correction records only the **difference** (the top-up or the claw-back).

This happens on the **Disputes** screen — when an employee flags a pay issue, you handle it there.

```
   1. FIX THE CAUSE        2. PREVIEW            3. APPLY               4. SETTLE
 ┌──────────────────┐   ┌──────────────┐    ┌──────────────────┐   ┌──────────────────┐
 │ correct the data │   │ see the      │    │ a "Correction"   │   │ pay the          │
 │ (clock-ins,      │──►│ before/after │──► │ payslip is made; │──►│ difference (or   │
 │  salary, leave)  │   │ difference   │    │ employee notified│   │ claw it back)    │
 └──────────────────┘   └──────────────┘    └──────────────────┘   └──────────────────┘
   in the app           nothing changes      original is kept       outside the app
                        yet — just a check    untouched
```

- **Preview first.** It shows the exact before/after so you confirm a real change. If you haven't fixed the underlying data yet, it tells you "nothing changed — fix it first."
- **The original is never altered** — the correction is a separate slip showing only the +/− change, with the reason.
- **The app doesn't move money.** You pay the difference to (or recover it from) the employee yourself. They're notified automatically and get a correction note.

---

## Good to know

- 💡 **Made a mistake?** Before finalizing, click **Cancel** and start again. Nothing is lost.
- 📅 **Run months in order** — finish one month before starting the next.
- 🔒 **Finalize locks it.** After that, fix one person with a **Correction** (see above) — you don't re-run everything.
- 🎁 **December** automatically adds the **end-of-year bonus** = the employee's **total pay for the year ÷ 12** (about one month's salary for someone who worked the full year). They need ~12 months of service to qualify. You don't calculate it — it appears on the December payslip.
- 🧮 **Taxes are calculated for you** — you never do the math.
